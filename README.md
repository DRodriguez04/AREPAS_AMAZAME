API REST desarrollada en Java con Spring Boot para la gestión de productos (inventario) de un negocio local de venta de arepas.

Este proyecto está basado en un caso real y permite administrar productos como arepas, bebidas y otros insumos.

Tecnologías utilizadas
Java 8
Spring Boot 2.7
Spring Data JPA
H2 Database
JUnit 5
Mockito
MockMvc
OpenAPI (Swagger - Springdoc)
